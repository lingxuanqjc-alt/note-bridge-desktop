# 1.0.0 正式版本的发布范围

笔记互迁 1.0.0 是按本文限定支持范围发布的正式版本。版本名称不再使用开发预览或候选版；这不表示最初覆盖所有内容、设备和环境的广泛验收计划已经全部完成。公开推送和 Release 仍须用户审阅实际产物后明确批准，本次版本整理不执行发表。

## 本版提供的功能

| 项目 | 1.0.0 支持范围 |
| --- | --- |
| 桌面环境 | Windows 10／11 x64，使用 Microsoft Edge WebView2 Runtime；提供安装版和完整目录便携版 |
| 平台 | 小米笔记、OPPO、vivo、华为备忘录、荣耀、魅族和 WPS；按各平台当前已实现协议读取和迁入 |
| 登录 | 用户在官方网页完成登录、验证码和设备验证；七平台使用独立进程及临时私密目录，会话仅在本次运行中使用 |
| 导出 | TXT、Markdown、HTML、DOCX，支持合并文件及每条独立文件；保留可获取的原件与相对资源路径，支持 ZIP 打包 |
| 离线阅读 | HTML 目录、摘要、多个关键词同时匹配、月份筛选、结果跳转和分页；媒体播放受浏览器格式支持限制 |
| 迁移 | 读取来源后选择笔记，向目标新增并保留源数据；支持已实现的正文、常见样式、分组和 PNG/JPEG 原件 |
| 可靠性 | 账号隔离、附件校验、进度与取消、格式差异报告、已确认版本跳过、跨版本未知写入阻断及只读迁移记录 |

具体操作见[使用指南](GUIDE.md)，逐平台限制见[兼容性矩阵](COMPATIBILITY.md)。不支持的附件或内容必须停止或明确报告，不能静默删除后报成功。

## 已知限制

- 云端迁入附件仅支持 PNG/JPEG 原件。小米要求官方检查确认的非加密账号，单张最多 4 MiB，不支持多块上传。OPPO 服务端要求分片时停止，不发送该条笔记新增请求，已分配资源保留供核对。华为沿用 10 MiB 协议限制，不宣称上限实测。音视频、其他文件及不支持的图片格式可使用本地导出路径。
- 富文本按目标能力转换。OPPO 官网把代码块与行内代码显示为普通文字，原始标记和文本仍保留供导出；魅族表格可能转换为无边框的普通文字；WPS 链接明文保留但首次打开不保证可点击。标题层级、引用、表格、代码、时间及其他样式差异以报告为准。
- 厂商会话可能过期，登录可能触发环境风险、验证码或设备检查；隔离登录进程不能延长云端会话或绕过验证。华为适配的是“备忘录”，不是另一项“华为笔记”服务。
- 专有手写、涂鸦、思维导图、加密内容及未经验证的旧账号入口不属于全面兼容范围。未承诺所有厂商接口版本、账号、机型或完整原生排版一致。
- 写入结果不明时保留待核对记录，不自动重发；修改源正文不能绕过旧版本的未知写入。应用不提供清除保护或假确认入口。

## 已有证据与未完成的广泛验收

以下是 0.1.0a1 阶段积累的实测事实，保留其日期、范围和原始失败；不记作 1.0.0 新安装包已完成相同检查：

- 非 OPPO 的 30 个方向由用户确认正常，按用户要求冻结。OPPO 相关 12 个方向的 24 条固定直接来源样例完成目标内容、分组及限定源端后置核对；BI4 使用独立恢复证明，原失败报告保留。
- OPPO 官网核对了 OR1 与六个迁入双条，共 13 条、24 张图片；12 条完成限定标记修复，1 条无需修改。WPS、华为、荣耀另有六条十二图官网证据；小米两条四图只计已知视觉范围；vivo 用户确认正常，魅族无表格边框与声明降级一致。
- BI 历史构建完成 1685 项测试、本机 Windows 11 安装等 9/9 检查及冻结 EXE 合成登录隔离检查。这些历史结果和 SHA256 不替代 1.0.0 的独立构建、产物校验及发布审核。
- 七平台四格式×两模式的 56 项基础导出检查有历史记录；发现的 Markdown 等格式问题有单独修复回归。不能由基础转换数量推定所有内容与原生样式均已验收。

最初的广泛验收计划仍有完整内容／失败场景、全部页面与缩放状态、2 CSS 像素全状态对照、干净 Windows 10／11、手机同步及专有内容等缺项。本机测试不代替这些环境和内容。原 [acceptance.json](acceptance.json) 保持真实状态：56 项 `smoke_only`，42 项迁移、6 项桌面和 8 项视觉仍为 `pending`，历史 `formal_acceptance`／`release_ready` 不改成 true；这不是这些项目全部执行并失败。

源端“未变”证明只在原观察时点和明确范围成立。后续对 OR1 等既有样例的授权标记修复改变了版本，应使用独立修复证据；华为 BI4 原有 22 条正文没有重新核验。限定测试只读取工具生成的 vivo 样例，不把旧全账号缓存当作完整。
