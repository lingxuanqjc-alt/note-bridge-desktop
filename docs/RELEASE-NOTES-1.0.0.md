# 笔记互迁 1.0.0

笔记互迁 1.0.0 提供七平台笔记导出与迁移，支持在本地保存笔记、图片和附件，并将所选笔记迁入另一平台。

## 主要功能

- 小米、OPPO、vivo、华为备忘录、荣耀、魅族及 WPS 的官方登录、读取和跨平台迁入。
- TXT、Markdown、HTML、DOCX 的单／多文件导出、原始资源目录和 ZIP；HTML 提供目录、摘要、搜索与月份筛选，DOCX 合并导出提供可跳转目录。
- 迁移前逐条选择与兼容性提示，保留源数据、来源时间附注和分组信息；云端迁入图片限 PNG/JPEG。
- 七平台独立 WebView2 登录进程及临时私密目录，官方窗口提供刷新和返回官网菜单；凭据不交给应用前端或写入日志。
- 账号与资源隔离、取消和逐条结果、已确认版本跳过、跨版本未知写入保护及只读迁移记录。

## 格式与兼容性

OPPO 斜体、高亮及分隔线按官网支持的标记输出；代码块和行内代码的官网显示为普通文字，原始标记及文本保留供导出。华为多图片下载减少了重复准备请求，Markdown 与 DOCX 导出包含强调、列表及组合样式的转换修复。

小米仅支持已确认非加密账号与单张不超过 4 MiB 的 PNG/JPEG；OPPO 要求分片时停止，保留已分配资源供核对；华为入口对应备忘录。表格、代码、链接及其他样式依目标能力降级并报告。专有手写、加密内容、全部机型与会话长期稳定性不作全面兼容承诺，详见[兼容性矩阵](COMPATIBILITY.md)。

本版按限定范围提供支持；已有验证与干净系统、全部缩放、手机同步等广泛验收的剩余项目见 [1.0.0 发布范围](RELEASE-SCOPE-1.0.0.md)。
