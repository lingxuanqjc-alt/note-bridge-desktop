2026-09-07 最新用户验收：“我验收了除了涉及oppo以外的路径均已正常”。已记录非 OPPO 的 30 个方向由用户验收正常，停止非 OPPO 的后续测试和重新登录请求。后续只继续 OPPO 相关路径与必要交付。

当前可审阅的是 `0.1.0a1` 六目标开发预览。BF 安装包已通过 1160 项完整测试、前端及 Windows 打包，并通过本机 Windows 11 的 9 项安装、升级、卸载及导出保留检查。后续验收工具修改不改变生产程序；具体文件与校验值见交付目录。

华为原有笔记完整性与各次唯一新增已有独立回读证据；BD18、BD19 的原失败文件保留，没有重启旧批次。官网检查与 API 回读分别记录，不把接口成功扩大为手机同步或完整排版通过。会话长时间稳定性尚未证明。

vivo 后续只读取确认回执绑定的工具生成 ID；不遍历或补读私人笔记。新的迁移只用固定原始来源；历史迁入的只读核对不把旧链式样例重新作为新来源。未知写入继续隔离，不自动重发。

风险解除且登录会话可用后，剩余 OPPO 相关验证与必要交付暂估 **3–5 小时有效执行**。外部风控等待、新增协议问题及尚未提供的干净系统／手机环境不计入此估算，不承诺正式发布日期。退出 Codex 后的登录方式见 [OPPO 登录说明](OPPO-LOGIN.md)。

正式七平台发布仍需处理 [验收登记](acceptance.json) 的未覆盖项目。本机验收不能替代 Windows 10／11 干净环境、各缩放和手机同步；未完成项不会以文档整理补成成功。范围与逐方向证据见 [迁移矩阵](MIGRATION-MATRIX.md)，当前交付边界见 [审阅说明](REVIEW-PACKAGE.md)。
