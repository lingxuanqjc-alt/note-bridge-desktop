## 已核对的字段和阶段

| 阶段 | 官网行为 | 独立实现需要遵守的边界 |
| --- | --- | --- |
| 分块 | 工作线程按 4 MiB 切分文件，计算整文件 SHA1 和每块 size、MD5、SHA1；非加密路径上传原始块字节 | 摘要用于协议兼容，不作为密码或身份验证；空文件及文件类型应在写入前校验 |
| 申请 | POST `/file/v2/user/request_upload_file`，表单 data 为 JSON；type 为 note_img，storage 包含 filename、size、sha1、mimeType、kss.block_infos | 浏览器 Blob 的 JSON 表示与传输字节分别处理；有效 PNG 的官网拦截请求已与独立编码逐字段相等 |
| 去重 | 申请响应若已有 fileId，直接返回 fileId、mimeType、digest | 必须验证响应形状及后续附件原件，不能只因请求成功便认定上传完成 |
| 块上传 | 否则读取 storage.uploadId 和 kss.node_urls、file_meta、block_metas；已存在块复用 commit_meta，其他块 POST `/upload_block_chunk`，参数含 chunk_pos、file_meta、block_meta | 上传主机必须核对来源及允许范围；不得向文件服务发送账号 Cookie；结果不明停止，不照搬官网自动重试 |
| 提交 | POST `/file/v2/user/commit`，表单 commit JSON 包含 storage.uploadId、size、sha1、kss.file_meta、commit_metas | 确认 fileId、digest 后仍需真实下载与原件比较 |
| 笔记关联 | 编辑器插入文件标识并更新 setting.data，附件元素包含 fileId、mimeType、digest | 正文引用和附件元数据必须同时保留，迁入后完整回读验证 |

公共请求工具使用表单编码，并从内存中的当前会话添加 serviceToken。该值不进入研究记录、日志或测试文件。

## 尚未通过

加密路径由账号的端到端加密状态控制，涉及 AES-CTR、记录密钥与 encryptInfo。尚未验证的加密账号不能降级为明文上传，也不能关闭用户加密设置。当前测试账号的非加密申请、服务端响应、文件节点及路径、提交、双图片笔记关联已取得 AC6 样例证据。加密账号、多块图片、复杂内容及完整迁移方向仍待实测。

公开代码仅用来理解协议，未复制进应用执行或作为依赖分发。采集资源与私有会话均不进入源码归档。小米图片迁入及依赖它的完整方向继续保持未通过。
