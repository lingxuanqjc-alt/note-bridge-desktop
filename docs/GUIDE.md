# 笔记互迁使用指南

本指南适用于笔记互迁 1.0.0 正式版本。支持范围见 [1.0.0 发布范围](RELEASE-SCOPE-1.0.0.md) 和[兼容性矩阵](COMPATIBILITY.md)；不支持的内容或失效会话会显示明确提示，不会返回模拟笔记或假成功。

## 启动与登录

安装版双击桌面“笔记互迁”。便携版解压整个目录，再双击 `NoteBridge.exe`，不要只复制 EXE。源码环境准备完成后，双击项目中的 `启动笔记互迁.cmd`。

先在手机的系统设置或笔记应用中开启云同步，等待同步完成。点击对应平台的“登录”，在官方网页中输入账号、密码和验证码，然后进入笔记页。回到“笔记互迁”点击“已完成登录，检查账号”。只有实际笔记权限检查成功，才显示“已登录”。

登录页是平台的官方网页。当前源码为七个平台分别使用独立的 WebView2 登录进程和临时私密浏览器目录，按需打开窗口。应用主界面不接收密码、验证码或 Cookie；取消登录或退出应用后清除会话，下次使用需要重新登录。导出页和迁移页共享同一账号状态。隔离处理已通过本机合成测试，发布包实测记录见检查点；厂商仍可能要求重新登录或显示环境风险提示，详见[登录窗口与会话隔离](LOGIN-ISOLATION.md)。

登录页面卡住时，可在官方窗口顶部的“页面”菜单点击“刷新当前页面”；需要回到入口时，点击“重新打开官网”。这两项保留当前窗口的会话，只操作该平台。若要清除该平台的登录状态，再从应用中取消登录后重新登录。

## 导出

1. 点击平台卡片，选择笔记来源，完成登录。
2. 点击“获取笔记”，检查数量和结果提示。
3. 选择 TXT、Word、Markdown 或 HTML，以及单文件或多文件。
4. 点击“导出笔记”，在系统目录选择器中选择保存位置。
5. 完成后点击“打开目录”；“附件”打开本地资源缓存，“笔记”打开最近导出目录。
6. “打包”将最近导出及其资源一起生成 ZIP，选择导出目录之外的位置保存。

每次导出建立新目录。重名笔记按序号区分，空标题使用正文首行或“无标题”。导出目录中的 `导出说明.json` 记录数量和差异提示；请保留它及 `resources` 文件夹。

TXT 只表达文本、列表标记和附件路径；Word 中音视频和一般文件保留为相对链接；不支持内嵌的图片保留原文件并报告。格式降级、附件缺失和源内容异常都会进入提示，不能只看输出文件是否存在。

## HTML 离线阅读

合并 HTML 自带目录、摘要、正文、搜索框、创建月份筛选和页码滑块，可直接在浏览器打开，无需软件或网络。

搜索多个词时，用空格隔开，显示同时包含全部关键词的笔记。点击目录项切换结果；Enter 跳到下一个结果，Shift + Enter 跳到上一个。正文命中词高亮。图片、音频和视频从相对资源目录加载，媒体格式仍受浏览器支持范围限制。

将 HTML 发到其他设备时，请发送完整 ZIP。只发送 HTML 文件会缺少附件。

## 迁移

1.0.0 开放小米、OPPO、vivo、华为备忘录、荣耀、魅族和 WPS 七个迁入目标，按下列协议与格式范围提供支持。已有固定样例的迁移和内容核对记录，不代表所有账号、机型和专有格式均兼容。新版本产物见[下载说明](DOWNLOAD.md)，历史实测见[检查点](CHECKPOINT.md)。

1. 左侧选择迁出平台，右侧选择不同的迁入平台，分别完成登录。
2. 点击“开始迁移”，软件读取一次来源，在“选择要迁移的笔记”中显示每条的兼容性与降级提示。
3. 默认全选。对不兼容或待核对的笔记，可取消选择或点击“仅选兼容笔记”；软件不会自动删掉附件来迁入。未选条目会进入报告。
4. 确认所选范围，软件使用本次读取的内容向目标新增笔记。若要读取云端的新改动，请取消选择窗口后重新开始；切换账号或缓存变动会使旧选择失效。
5. 查看任务结果和差异提示，再在目标官网或手机检查正文、图片和分组。成功回执不等于所有内容已独立回读通过。

当前迁入附件仅接受原件为 PNG/JPEG 的图片。小米单张最多 4 MiB，并在实际写入前检查当前账号的非加密模式；加密或无法确定模式时停止写入。音视频、其他文件以及不支持的图片格式可先完整导出到本地。

华为入口对应“备忘录”，不是另一项“华为笔记”服务。标题层级、表格、代码及部分文字样式迁入时可能转为普通文字，具体差异进入报告；会话过期或请求被拒绝时按任务结果处理，不因重新登录而清除未知写入记录。

OPPO 支持已验证的正文、分组与 PNG/JPEG 图片，已修正斜体、高亮和分隔线的官网显示。代码块和行内代码在官网显示为普通文字，差异会明确提示；代码文字和原始标记保留供本地导出使用。若服务端要求图片分片上传，本版会停止，明确提示未发送该条笔记新增请求，并保留已分配资源供核对。

格式转换后的文字可见，不一定保留原来的布局。例如 0.1.0a1 阶段 OPPO→魅族的表格按报告转为制表符分隔的普通文字，用户确认没有表格边框，与预先声明的降级一致；这不算表格原样保留。该阶段用户也已确认 OPPO→vivo 样例显示正常。

迁移不会删除源笔记。同一版本已确认成功的记录会跳过；结果不明的记录标为“需要核对”，修改源正文也不能绕过旧版本的待核对记录。选择原迁移的双方账号，点击底部“迁移记录”，可只读查看本地回执、目标标识和资源状态，包括已关联的旧版本记录。缺少来源关联的旧记录可能无法显示，列表为空也不代表没有历史迁入。此版本没有清除保护或手动改成成功的入口；请保留记录并在目标官方页面核对。

## 错误与退出

“部分完成”表示已生成内容但有差异；“失败”表示流程没有正常完成；“需要核对”表示目标端可能已经写入。“日志”入口打开经过限制的任务报告，不包含原始 HTTP 响应、Cookie 或异常请求地址。

任务运行时，先在结果窗口取消，等待当前请求返回，再退出。关闭登录弹窗和取消登录是两个操作；后者会关闭官方窗口并清除本地账号状态。

卸载按安装清单删除程序文件，保留缓存及用户导出文件。用户自行移动、改名或删除导出目录后，应用不会自动找回该目录。
