# 0.1.0a1 开发预览说明

> 版本状态（2026-09-08）：当前正式版本为 **1.0.0**，以[1.0.0 发布范围](RELEASE-SCOPE-1.0.0.md)和[发布说明](RELEASE-NOTES-1.0.0.md)为准。下文保留 **0.1.0a1 阶段的历史快照**；其中“当前”“预览”“待发布”、测试数量和工件 SHA256 均对应当时，不代表 1.0.0 的构建或发布审核结果。原广泛验收的缺项和真实登记状态保留，不改写为通过。

源码及 BI 安装版、便携版均开放小米、OPPO、vivo、华为备忘录、荣耀、魅族、WPS 七个受限开发预览迁入目标。PNG/JPEG 原件、账号隔离、跨版本未知回执保护继续强制生效；小米限已核实非加密账号及单张 4 MiB。OPPO 大文件分片未完成实测，不宣称全面支持。 版本保持 `0.1.0a1`，`release_ready=false`。正式迁移登记仍为 0/42；用户确认与固定样例通过不等于正式 42 方向及桌面环境全部通过。

BI 七目标开发预览已通过 1685 项完整测试、前端构建、PyInstaller/NSIS；便携包 2,349 个文件逐一校验一致，本机 Windows 11 中文路径安装、升级、卸载保留导出等 9/9 项通过。新冻结 EXE 的独立登录子进程、会话隔离及临时目录清理已用本地合成页面验证；该检查不访问厂商或个人资料，也不代表厂商会话永久有效。

## 本轮变化与核对

- 七平台使用独立 WebView2 登录进程和随机私密目录；官方窗口的“页面”菜单可刷新当前页面或重新打开官网。凭据仅在后端内存传递，不承诺消除厂商风控或会话过期。
- OPPO 已按官网规则使用 `<i>` 斜体、带内联背景色的 `highlight_color_yellow` 高亮和 `hr-style-solid` 分隔线；下划线按官网渐变线与对应模型标记核对。代码块与行内代码在官网显示为普通文字，差异明确报告，原始代码文字及标记保留供本地导出。
- OPPO 原始综合样例 OR1 与六个迁入双条，共 13 条、24 张图片，已完成精确身份、版本、分组、完整非空白正文顺序、目标保留样式、结构及图片解码的官网核对。12 条受影响样例已作限定格式修复，BI5[0] 无需修改；代码显示降级单列，不算代码布局原样保留。
- OPPO 相关 12 方向、24 条固定样例的目标及源端后置均有证据；11 个原始 API 通过批次，华为 BI4 两条由独立读取补齐。非 OPPO 30 方向由用户确认后冻结。
- WPS、华为、荣耀共六条及十二张图片的官网检查通过；小米两条四图只计已知视觉项目。vivo 用户确认正常；魅族无表格边框与预定普通文字降级一致。

源端后置“未变”只在各原始证明的观察时点及固定范围成立。此后 OR1 与部分既有 OPPO 目标进行了有独立授权和证据的格式标记修复，版本随之变化；不能把旧来源指纹／版本证明写成当前永久未变。修复只更新既有样例，不新增笔记，旧失败、原始源端证明和修复证明分别保留。

## 功能和保护

独立桌面界面、七平台读取、四格式单／多文件导出、离线 HTML 阅读和 ZIP 均保留。迁移前读取一次来源，再确认笔记选择；账号或缓存改变使旧选择失效。同一来源旧版本的未知写入仍阻断新写入，提供按双方账号隔离的只读回执查看。

干净 Windows 10/11、各缩放与全部界面状态、手机同步、完整空白排版及未覆盖内容／失败场景仍有缺项。本机检查不代替这些条件；已声明降级、历史未知写入和失败证据保留，不自动重发或清除保护。

华为 BI4 原 22 条仅核对存在和读取期间元数据稳定，未重读全部正文。vivo 后续测试仅使用明确工具样例，不读取私人正文或将旧全账号缓存标为完整。56 项历史导出检查和 Markdown 修复按各自范围计量，不能视为所有内容均完整验收。
