## 正式证据关联格式

`check-release.py` 验证矩阵覆盖范围及证据关联，不替代对真实设备、内容完整性和原始日志的人工审阅。正式报告的 `formal_acceptance` 必须为 JSON 布尔值 true；`checks` 中每项使用 `group`（exports/migrations/desktop/visual）、该矩阵项的身份字段和 `status`。例如迁移项字段为 source、target、status。一个报告可覆盖多个实际完成的案例，但每个案例只出现一次。矩阵的 evidence 使用项目内相对路径；私人原始证据仍放在 `.private`，不得为凑齐矩阵而把开发报告改成正式报告。
