# 退出 Codex 后登录 OPPO

> 版本说明（2026-09-08）：当前正式版本为 **1.0.0**，支持范围见[1.0.0 发布范围](RELEASE-SCOPE-1.0.0.md)和[发布说明](RELEASE-NOTES-1.0.0.md)。本文技术说明和协议依据保留；带日期的测试、构建及登录尝试属于 0.1.0a1 阶段证据，不代替 1.0.0 的新产物验证，也不承诺全部设备或会话长期兼容。

在日常浏览器打开 [OPPO 云服务](https://cloud.oppo.com/)，可收藏该页面。此入口独立于 Codex，不需要保持 Codex 运行。

软件当前使用独立 WebView2 登录进程，提供“页面”菜单用于刷新及返回官网，见[会话隔离说明](LOGIN-ISOLATION.md)。本轮迁移和构建进度以[检查点](CHECKPOINT.md)为准；下方的早期登录尝试不代表当前验收状态。

1. 使用准备测试的网络进入官网，按官方步骤完成登录和验证。
2. 进入笔记页并打开一条笔记，确认这个浏览器中可以正常使用笔记。
3. 下次回到本项目时告知“OPPO 官网已能登录并打开笔记”，继续 OPPO 相关验收即可。

如果仍提示环境风险，保留提示结果并暂停。网页登录是否成功由 OPPO 决定，收藏链接不会绕过风控。

普通浏览器登录状态与软件测试会话分别管理；恢复软件测试时仍需在实际测试窗口检查账号。无需导出或发送密码、Cookie 等凭据。

2026-09-07 早期登录尝试记录：用户确认普通 Edge 已登录并可打开正文，但单独启动的 Edge 测试窗口仍提示环境风险。后者已关闭，当时没有执行测试写入，不再要求重复尝试同一种窗口。随后使用“笔记互迁 · OPPO 测试登录”的 WebView2 方式并直连测试后端；18 项离线测试通过，用户确认正常进入，实际账号检查也通过。这个历史结果仅确认当时会话可用。若后续再提示风险，停止尝试并记录结果。普通 Edge 保持原样，不导入其浏览器配置或登录凭据。

用户已于 2026-09-07 确认除 OPPO 外的路径均验收正常，其余平台不再要求重新登录或重复验收。

早期单独创建网页登录快捷方式的操作被自动审批审核拒绝，当时未创建；可使用上方官网链接。这与应用安装包中的桌面快捷方式是分别记录的操作。
